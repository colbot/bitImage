# bitImage - 图像转 LCD 单色点阵工具

[![在线演示](https://img.shields.io/badge/在线演示-colbot.github.io%2FbitImage-38bdf8?style=flat-square&logo=github)](https://colbot.github.io/bitImage/)

**[English](README.md)** | **[简体中文](README_CN.md)**

**bitImage** 是一款轻量纯粹、单文件架构的 HTML5 网页工具，专门用于将彩色或灰度图像转换为用于单色 LCD、OLED、电子墨水屏（E-Paper）显示的 1 位单色位图掩码点阵。无任何外部依赖，完全在本地浏览器运行，具备实时动态预览、Floyd-Steinberg 误差扩散抖动算法、屏幕宽高比自适应裁剪框以及一键生成 C 语言字模点阵数组等强大功能。

🌐 **在线体验地址：** [https://colbot.github.io/bitImage/](https://colbot.github.io/bitImage/)

---

## ✨ 核心特性

- **🚀 零依赖单文件，纯本地运行**：
  - 整个应用完全封装在单个自包含的 HTML 文件（[`index.html`](index.html)）中。
  - 完全离线可用，不依赖任何 CDN 或外部 JavaScript 库。
  - 完美兼容 **Microsoft Edge**、**Google Chrome**、**Mozilla Firefox** 和 **Safari** 等现代主流浏览器。
  - 所有图像算法均在浏览器端本地执行，保护隐私，无任何数据上传至服务器。

- **📁 便捷载入与内置测试图样**：
  - 支持拖拽或点击浏览载入本地图片文件（支持 `PNG`、`JPEG`、`WEBP`、`BMP`、`GIF`、`SVG` 等常见格式）。
  - 页面加载时自动生成精美渐变与几何测试图样，开箱即可体验全部算法效果。

- **📐 灵活的目标 LCD 规格设置**：
  - 自定义 LCD 目标分辨率（宽度和高度像素数）。
  - 内置常见显示屏预设：
    - `128 × 64` (SSD1306 OLED / ST7920 液晶屏)
    - `128 × 32` (Mini 0.91 寸 OLED)
    - `256 × 64` (宽屏点阵屏)
    - `84 × 48` (诺基亚 5110 PCD8544 液晶屏)
    - `160 × 160` (方形点阵屏)
    - `240 × 128` (T6963C 控制器屏)
  - 支持非正方形像素点：可自定义**像素宽度比例**与**像素高度比例**（如 $1.0 : 1.5$ 或 $2.0 : 1.0$）。
  - 选框按物理屏幕宽高比锁定：根据 $(W \cdot R_w) : (H \cdot R_h)$ 比例约束选框，避免因像素点比例导致图像拉伸变形。

- **✂️ 交互式目标区域选框**：
  - 原图预览区悬浮半透明遮罩与九宫格构图辅助线。
  - 8 个高精度锚点支持拖拽缩放与边界约束，平滑防抖。
  - 点击图片外部任意区域即可自动将选框平移居中至点击位置。
  - 提供“重置选框至全图”按钮，快速映射全画幅。

- **⚙️ 1 位单色二值化与抖动算法**：
  - **二值化阈值滑动条**：支持 `0` 至 `255` 平滑调节，带实时数值显示。
  - **Floyd-Steinberg 误差扩散抖动**：消除渐变色块断层，让单色屏幕也能细腻呈现照片中的丰富层次与阴影细节。
  - **结果反转（0/1 互换）**：一键翻转点阵极性，适配共阳/共阴或不同驱动芯片的显存逻辑。
  - **自定义点阵颜色**：可自由选取点亮像素颜色（结果 1）与背景底色（结果 0）。
  - **模拟 LCD 像素间隙点阵感**：开关点阵网格缝隙，真实还原点阵屏幕质感。

- **⚡ 纯实时动态渲染**：
  - 调节滑动条、拖动选框、修改分辨率或更换颜色均即时呈现结果，操作行云流水，无需额外点击“转换”按钮。
  - 丰富的缩放倍率控制（`自适应缩放`、`1x`、`2x`、`3x`、`4x`、`6x`）。
  - 实时显存指标统计：总像素数、点亮像素数（1）、熄灭像素数（0）以及显存字节大小。

- **💾 嵌入式开发代码导出**：
  - 多种点阵取模格式可选：
    - `逐行水平扫描 (X-first, MSB 高位在前)`
    - `逐行水平扫描 (X-first, LSB 低位在前)`
    - `页式垂直扫描 (SSD1306 / 诺基亚 PCD8544)`
    - `原始十六进制 Hex 数组`
  - 一键**复制 C 语言数组**至剪贴板，直接粘贴进 Keil / IAR / PlatformIO / Arduino IDE 工程。
  - 高亮显眼的**下载 1-Bit 单色 PNG** 按钮。

- **🌍 双语支持**：
  - 顶部导航栏支持**中文 / English**一键无缝切换。

### 1. 在线使用
直接在任何现代浏览器中访问：[https://colbot.github.io/bitImage/](https://colbot.github.io/bitImage/)

1. 克隆代码仓库：

   ```bash

   xdg-open index.html
   # 或
   firefox index.html

   # macOS
   open index.html

   # Windows
   start index.html
   ```

## 🛠️ 推荐工作流

1. **载入图片**：将设计图或照片拖拽进上传区域，或点击选择本地文件。
2. **选择 LCD 规格**：在预设中选择目标屏幕（如 `128x64`）或手动填入宽高及像素点比例。
3. **调整目标选框**：在原图预览区拖拽和缩放选框，框选出要在屏上显示的核心画面。
4. **调节画质参数**：
   - 拖动阈值滑动条调整画面明暗度。
   - 勾选“启用误差扩散抖动”观察过渡细节变化。
   - 若屏幕显示反相，勾选“反转结果 (0 与 1 互换)”。
5. **导出点阵数据**：
   - 选择目标控制器格式（如 `逐行水平扫描 MSB` 或 `页式垂直扫描`）。
   - 点击“复制 C 语言数组”，直接粘贴到单片机固件代码中。
   - 也可点击“下载 1-Bit 单色 PNG”保存单色图片素材。

## 📋 常见点阵取模格式对照

| 格式名称 | 扫描方向 | 字节排列规则 | 常见适用硬件 / 驱动库 |
| :--- | :--- | :--- | :--- |
| **逐行水平扫描 (MSB)** | 从左至右，从上至下 | 每字节 8 像素，左侧第一点为最高位 (Bit 7) | Adafruit GFX, ST7920, 电子墨水屏 |
| **逐行水平扫描 (LSB)** | 从左至右，从上至下 | 每字节 8 像素，左侧第一点为最低位 (Bit 0) | 部分自定义单片机驱动程序 |
| **页式垂直扫描 (Page)** | 8 行水平页，从左向右列扫描 | 每字节 8 像素垂直排列，最上方为最低位 (Bit 0) | SSD1306, SH1106, PCD8544 (Nokia 5110) |
| **原始 Hex 数组** | 连续 8 像素打包 | 连续打包二进制字节的十六进制输出 | 通用图形处理流 |
